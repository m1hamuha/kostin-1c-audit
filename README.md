# Экспресс-аудит 1С

Онлайн-инструмент быстрой диагностики базы 1С. Пользователь отвечает на 7 коротких вопросов о своей базе — версия, конфигурация, число пользователей, размер и возраст базы, интеграции и проблемы — и сразу получает готовый отчёт:

- **Индекс здоровья базы** (0–100) с цветовой зоной;
- **список рисков по приоритету** простыми словами (что это значит и почему важно);
- **план работ по этапам**;
- **ориентировочная оценка** по срокам и стоимости («от …»).

Есть кнопка записи на бесплатную 15-минутную диагностику и печать/сохранение отчёта в PDF.

## Запуск

```bash
npm install
npm run dev      # локальная разработка
npm run build    # сборка в /docs (для GitHub Pages)
npm run preview  # предпросмотр собранной версии
```

Весь расчёт отчёта выполняется в браузере — серверная часть не нужна.

## Стек

Vite · React · TypeScript · Tailwind CSS. Сборка кладётся в `docs/` и публикуется через GitHub Pages.
